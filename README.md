# Historical GDP per capita explorer — moved

**The interactive explorer now lives at [www.kochphilipp.com/data/historical-gdp](https://www.kochphilipp.com/data/historical-gdp/).**

This repository hosted the original Shinylive (webR) version of the explorer for

> Koch, P., Stojkoski, V., & Hidalgo, C. A. (2024). Augmenting the availability of historical GDP per capita estimates through machine learning. *Proceedings of the National Academy of Sciences*, 121(39), e2402060121. <https://doi.org/10.1073/pnas.2402060121>

Because that version ran R inside the browser, it took a long time to load. The new explorer uses pre-built static data and opens in seconds. It also offers CSV downloads, shareable links to specific views, and a citation block.

The old address, `philmkoch.github.io/historicalGDPpc_app/`, now shows a short notice and forwards visitors to the new explorer. The files of the former app remain in `docs/shinylive/` and `docs/app.json` for reference.

- **New explorer:** <https://www.kochphilipp.com/data/historical-gdp/>
- **Data and replication code:** <https://github.com/philmkoch/historicalGDPpc>
